# Reference Gaps

## Summary

The current project is good at proving one visible walkthrough route and several high-level landmark silhouettes. It is weak at exact scale, complete park coverage, hidden path topology, named zones that were not walked, and high-fidelity surface/detail reference.

## Critical Missing Evidence

| Gap | Severity | Why It Matters |
|---|---|---|
| True aerial/satellite/drone/survey map | Critical | The illustrated map is not enough for exact path geometry, distances, rotations, or building footprints. |
| Complete west/north route coverage | Critical | Crooked Lantern Tavern, Nettleton Mill, Slanting Shanty, Loudon's Rest, Pigmyweeds Inn, Hex Trove, End of Haunt, and surrounding loops are not covered well enough. |
| Railway/station/train ground reference | High | The map shows Evermore Express/rail placement, but no usable station/train/track geometry exists in the frames. |
| Mythos/Lore/Aurora evidence | High | No direct files were found for these named categories. They cannot be built honestly yet. |
| Tavern reference | High | Crooked Lantern Tavern is map-only in this pack. Facade, interior, path context, and scale are missing. |
| Exact measurements/scale anchors | High | 720p walking video gives relative route feel, not metric dimensions. Need known distances, widths, or survey anchors. |
| Full facade coverage | High | Many buildings are seen from one angle only; backs/sides and roof geometry are missing. |
| Clear interior reference | Medium | Confection/cafe and raised hall interiors are dark/occluded. They support mood but not exact layout. |
| Seasonal variation | Medium | The pack captures October/Haunt dressing. Other Evermore seasons or baseline non-seasonal layout are not represented. |
| Legal/branding clearance | Medium | Visible names/signs/logos/story text should not be treated as permission to reproduce protected material. |

## Category-Specific Gaps

### Aerial Maps

No aerial maps were found. This is the single biggest blocker to exact map topology. Before high-fidelity world work, add a true overhead source and reconcile it against the illustrated map and route frames.

### Park Maps

The illustrated map is high-resolution and readable, but it is stylized. It should be used for labels and rough adjacency only.

### Walkthrough Frames

The 629-frame route series is complete and useful, but it is one path through one October walkthrough. It does not prove off-camera intersections, back sides, or hidden paths.

### Gatehouse / Entrance

Pumpkin arch and garden entry are visible. Vander's Keep/gatehouse itself is not captured well enough for exact reconstruction.

### Central Plaza

The route-facing plaza and Barter's Post side are usable. Full plaza footprint, exact stage placement, and hidden facades need more references.

### Market / Tavern

Market/vendor areas are visually present, but the tavern is not. Crooked Lantern Tavern, full west-side market lanes, and exact shop identities need more source photos/video.

### Water / Bridge / Ruins

This is one of the strongest areas. Still missing: exact ruin footprints, backside of walls, water depth/edge construction, and dimensions of the raised hall/deck.

### Archery

The activity yard is visible but not clearly signed as exact archery. Need target lanes, range boundaries, props, safety fencing, and label confirmation.

### Pavilion / Stage

Big Top is clear, and the gravel courtyard/stage sightline is visible. Exact performance stage/pavilion design remains incomplete.

### Railway / Train

Map-only. Need ground photos or video of station, train, tracks, crossings, and how the rail route relates to guest paths.

### Mythos, Lore, Aurora

No direct reference found. These should not be included in a build except as explicitly marked placeholders.

## What Is Safe To Build Now

Safe: a limited gray-box route prototype of the captured walkthrough, using obvious uncertainty labels.

Not safe yet: full-park claims, exact scale claims, high-fidelity building replicas, Mythos/Lore/Aurora, railway/train, tavern, and unseen west/north loops.
